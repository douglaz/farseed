Relay details

Registering the machine SSH public key with the provider does not enroll the relay. Before configuration, copy the separate relay public key and ask your relay operator to enroll it. You still need published pins and approvals for the goal, class, access and installation declaration.

Use letters, digits, - and _, starting with a letter or digit. You can change it.

Will this machine serve people you have never met? If unsure, choose Not sure.

Approving orders this machine from the provider now. With an account this page made for you, nothing is charged until you pay its first invoice yourself, in your wallet.

If you don't pay, the provider deletes the machine after about an hour. Once paid, this page can't cancel or refund it: the machine runs for the period you paid unless the provider ends it early. If you entered your own provider account, it may also pay automatically: see below.

What if I change my mind, or use my own account?

If you entered your own provider account above and it holds account credit set to be spent automatically, requesting the invoice may pay it from that credit, with no wallet step. If credit pays all of it, this page can't finish setting up the machine, so turn that setting off at the provider before you request the invoice. The provider also turns on automatic renewal for new machines, so that account's saved payment method or such credit can pay each later period without asking; you can turn renewal off at the provider once the machine exists.

The invoice you request is valid for about 10 minutes, and this page can't issue another. If it expires unpaid, wait until the provider has deleted the machine (about an hour after the order, or once the invoice expires if that is later), then press Close purchase and start again.

With an account this page made for you, you have no way to delete a paid machine early: it runs until its paid period ends unless the provider ends it, and if the provider then returns the unused time as account credit, this page can't use or return it. If you entered your own provider account above, you can delete the machine at the provider yourself, unless an abuse case is open against it; the provider returns the unused time as credit on that account, not as money back.

The machine provider requires a verified email address before it creates a machine. Your address goes to the provider only; tau-web uses it for nothing else. It is kept encrypted in this browser so the page can check that the provider verified the address you entered.

Open the link the provider sent to the address you entered. It is valid for about 24 hours. The page checks every 20 seconds while visible and continues your approved purchase when that exact address is verified.

If the link expired, open the original link first so the provider can clear it, then request a new link below. Sending again while a token still exists does not send another link. If the original link is unavailable or clearing fails, seek help from the provider; automatic resend is unavailable. To use a different address, enter it above yourself.

Existing machine

This PoC supports one existing machine per fresh local store. Each machine name permanently binds these connection fields, pin, profile and elevation. To change them, use a fresh local store and a new name; keep the current store for its task history. Obtain the host fingerprint independently; a presented SSH key is never accepted here.

4 Setup

Setup options

After enrollment, configure inference, then press Start session for the displayed model and machine. Copy its public keys. Install the SSH line and enroll the separate relay public key with the relay operator.

Set the session’s goal. Accept it with commands that check the result. Edit and propose the installation declaration, then approve its requirements card. Press Resume to continue. Commands require that approval.
